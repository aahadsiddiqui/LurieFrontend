# Agents System

A comprehensive AI agents interface that perfectly replicates Microsoft 365 Copilot's design while being customized for healthcare information systems.

## 🎨 Design Features

### Visual Design
- **Microsoft 365 Copilot-inspired interface** with healthcare customization
- **Identical layout structure** to Copilot's Agents page
- **Consistent design language** across all agent interfaces
- **Responsive design** optimized for healthcare workflows
- **Smooth animations** and professional interactions

## 🤖 Agents Interface (`/agents`)

### Header Navigation Tabs
- **Lurie AI Admin** - System administration and configuration
- **Clinical Coach** - Clinical decision support and patient care
- **Research Coach** - Research data analysis and evidence-based medicine
- **Meeting Notes Coach** - Meeting documentation and collaboration
- **"See more" link** - Additional navigation options
