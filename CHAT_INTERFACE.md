# Healthcare Chat Interface

A modern, Microsoft 365 Copilot-inspired chat interface designed specifically for healthcare organizations.

## 🎨 Design Features

### Visual Design
- **Clean, modern interface** matching Microsoft 365 Copilot aesthetic
- **Healthcare-focused branding** with medical icons and colors
- **Responsive design** that works on all screen sizes
- **Smooth animations** and hover interactions

### Chat Interface Components

#### 1. Chat Header
- **AI Assistant branding** with bot icon and "Powered by Lurie AI"
- **Online status indicator** with green dot
- **Professional healthcare context**

#### 2. Message System
- **User messages** - Blue bubbles on the right
- **AI responses** - White cards on the left with shadow
- **Typing indicators** - Animated dots when AI is responding
- **Message metadata** - Sources, confidence scores, timestamps

#### 3. Interactive Features
- **Quick suggestions** - Healthcare-focused prompt suggestions
- **Message actions** - Thumbs up/down, copy, edit buttons
- **Voice input** - Microphone button for voice messages
- **File attachments** - Paperclip button for documents

#### 4. Input Area
- **Smart suggestions** - Context-aware healthcare prompts
- **Multi-modal input** - Text, voice, and file support
- **Real-time typing** - Instant message sending
